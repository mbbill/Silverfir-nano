- Dispatch is pointer-in-cell threaded code: at link time each cell's
  leading word is rewritten to its handler's address, frame-slot operands
  pre-scale to byte offsets, branch targets to cell byte offsets; the tail
  is `advance pc; load handler word; indirect branch`.

- Handlers are emitted into executable memory at instance setup by a
  self-contained micro-encoder private to the interpreter (arm64 first) —
  deliberately not the JIT's encoder — under fixed register roles: pc,
  frame base, exit-state pointer, memory-0 base and length, current cell
  base, globals base, native return-stack cursor and limits, and a
  dispatch counter.

- Handler variants are generated by class loops over each operand's
  residency (frame slot, inline const, accumulator) and the destination's
  (frame, accumulator), keyed directly on the instruction's flag bits.

- Anything without a native handler exits the chain with a reason code;
  the driver recovers the current function from the pc through a range
  map, executes the original instruction in the shared executor, and
  re-enters. Memory-0 loads and stores carry inline bounds checks against
  the length register; other memory indices take the slow path.

## Facts

- 2026-07-24 measurement: the full float family went native in one pass
  (70 ops: arithmetic, compares with unordered-false cset mapping,
  copysign as an integer bit-splice, conversions, saturating truncs via
  fcvtzs/fcvtzu's exact wasm semantics, reinterprets as raw-bit moves)
  plus NEON popcnt; f32 values stay zero-extended by S-width loads and
  W-width result moves. Wall clock: mandelbrot 14.5s → 1.5s (9.3×),
  c-ray 58.6s → 2.8s (20.8×), stream 11.1s → 1.8s (6.2×); spectest's
  float suites passed on the first green build (code).

- 2026-07-24 rationale: trapping float→int truncs pre-check the exact
  exclusive trap bounds on the un-truncated operand (the low-bound LE
  compare is unordered-true, catching NaN for free) so a native bail
  always means a trap; a bail that could succeed on the slow path would
  break the accumulator pairing, whose soundness rests on "producer
  bails ⟹ execution never reaches the consumer" (code).

- 2026-07-24 measurement: after the float pass every benchmark's exit
  population is exactly the permanent contract — host calls plus
  memory.grow/size and nothing else: coremark 31, lua fib 19, lua json
  84, sqlite 174, bzip2 193, stream 211, sha256 374, mandel 2.5k,
  lz4/c-ray = their WASI call counts. The overlapping-downward
  memory.copy also went native (backward 8-byte block), ending sqlite's
  last 96k exits (code).

- 2026-07-25 measurement: three dispatch-lane items landed together —
  ldp operand-pair loads across the seven hottest families, i32.and +
  branch fused to a tst-and-branch op (one fuse_cmp_br map entry), and
  adjacent staging movs merged into a strictly-ordered MovPair (pinned
  destinations link slow; local.set folding skips pairs). Interleaved

  (code).

- 2026-07-25 measurement: address-add fusion (a corpus-universal
  base+index pattern found by a static bigram census over all benchmark
  modules; single-use just-emitted i32.add folded into the memory op's

- 2026-07-25 pitfall: generalizing MovPair to cover `local.set`'s unfoldable
